# SpotAlert

Unusual-aircraft alert app (a JetTip-style spotter tool). Watches your airports and alerts you to special liveries, warbirds, tankers, testbeds, and the blocked military/government/private jets other trackers hide. Predictive inbound ETA, watchlists, spotting logbook, live airframe photos, and web-push. Deploy: see DEPLOY.md (Render) or DEPLOY_FLY.md (Fly.io).
